# Tài liệu

| Thư mục | Nội dung | Trạng thái |
| --- | --- | --- |
| `diagrams/` | Use Case, DFD mức 1/2, ERD, Microservices Architecture Diagram (ảnh hoặc file nguồn) | Cần xuất từ tài liệu thiết kế |
| `api/` | Thiết kế REST API (URI, method, request/response, status code) | Đã có trong tài liệu thiết kế |
| `report/` | Báo cáo tổng quan tuần và báo cáo cuối | Chưa viết |

Tài liệu phân tích và thiết kế đầy đủ nằm trong tài liệu nhóm;
